# law_investigation

公开调查记录。不含判决书原告身份信息。

主力程序员自己打官司时的资源备忘。诉讼里卡住的，记成下次还能用的入口。

## 为什么记

判决下来不等于钱到账。法院网络查控不查工资。商业名录上的律师手机号会错位、多位、转接。工商页上的「负责人」不是业主，注销的个体户也不消灭已经形成的个人债务。这些都是办案时撞上的。这里只留核过的入口和用法，不留原告身份。

## 法律资源

查法条、案例、执行依据，先走这三家，不拿搜索引擎摘要当依据。

| 名称 | 用来干什么 | 入口 |
|---|---|---|
| 北大法宝 | 法规、司法解释、案例、时效 | https://www.pkulaw.com |
| 元典 | 法规与裁判文书检索；程序调用走开放平台 | https://www.chineselaw.com · https://open.chineselaw.com |
| 智合 | 检索、研究、文书、企业尽调 | https://www.zhiexa.com |

用法：

- 北大法宝、元典网页都要登录。引用前打开原文，核对是否现行有效、文号和条款号。
- 元典给程序用的是开放平台，要单独的 Key。网页检索和 API 不是同一条入口。
- 智合是产品账号，不是企查查那种公开按次开放平台。本次没有对接上按次接口，不猜路径，不把网页接口当成稳定 API。

## 工商查询

| 名称 | 用来干什么 | 入口 |
|---|---|---|
| 企查查 | 市场主体、存续或注销、负责人、分支机构、统一社会信用代码 | 页面 https://www.qcc.com · 付费对接 https://openapi.qcc.com |

用法：

- 先用页面对名称、信用代码、状态、负责人。截图只证明查询当日页面上有什么，不证明工资、社保或养老金。
- 要程序里反复查，走开放平台：注册、企业认证、开通接口、付款，都由本人做。
- 鉴权：`Token = MD5(AppKey + Timespan + SecretKey)`，十六进制大写。`Timespan` 是北京时间 10 位 Unix 秒，有效期 5 分钟。这两个头错了，返回状态 `115`。
- 页面能打开，不等于接口已开通。

## 主要经验

胜诉后卡住的是执行法院、材料怎么送进去、网络查控查不到工资、起诉到执行之间没有财产保全，以及胜诉不会自动强制执行。细节在 [漯河](漯河/README.md)。到 2026-10-16，12368 还没有打通确认，EMS 也还没有寄出。现有材料里没有保全裁定。下面是下次照做的做法，不是已签收、已冻结的记录。

### 执行法院

民事生效判决，由第一审法院执行，或者由与第一审法院同级、被执行财产所在地的法院执行。

这件一审在漯河市源汇区人民法院，案号（2025）豫1102民初4348。默认向源汇区法院申请执行。漯河中院是上诉法院，地址在郾城区辽河路 501 号，不是这件的执行立案点。

工资线索在临颍县。临颍县法院和源汇区法院同级，但「可能领工资」还不是已经查明的财产。没有财产所在地的证明，不改去临颍立案，也不向两个法院同时申请。

公开网页写源汇区法院在大学路，有的写大学路 113 号。邮寄和上门都不要抄导航站，以 12368 当次告知的诉讼服务中心窗口为准。

### 12368 和 EMS

1. 工作日打 `12368`。报源汇区法院和案号。问是否生效、对方是否上诉、是否已经立案执行、执行立案的收件地址和材料清单。热线答程序，不答这钱能不能要到。
2. 河南自 2021-07-19 起，向本省中级法院、基层法院申请执行，当事人不用再交裁判文书生效证明。依据是河南省高级人民法院通知，豫高法〔2021〕160 号。窗口仍要这份证明，打省法院或漯河中院的 12368 投诉。这条不包括最高人民法院和外省法院的文书。
3. 能在人民法院在线服务提交，就先网上立案。EMS 是到不了现场、网上被退回时的备用。
4. 邮寄只用 EMS。面单收件人写诉讼服务中心执行立案窗口。内件注明案号、联系电话、申请执行。地址必须是刚在 12368 确认的。
5. 寄申请书、身份证复印件、判决复印件、财产线索。判决原件自己留，除非窗口明确要原件。
6. 留 EMS 底单和轨迹。显示签收后，再打 12368 问材料有没有进立案。签收不是立案。拒收、退回、代收，都停，不连寄第二份。

### 网络查控

问题不是系统坏了。这件还没立案，总对总不会启动。口头请法院去查，法院说不查，卡在这一步。

立案之后，法院应当通过网络执行查控系统调查。它和现场调查效力相同。通常能命中银行存款、网络支付、证券基金、不动产、车辆、保险理财。工资、社保缴费、养老金发放账户不在这一键结果里。返回「无财产」只说明接入的库没有命中。

申请人要另交财产调查表。线索具体的，法院应在 7 日内核实，情况紧急的 3 日。依据是《最高人民法院关于民事执行中财产调查若干问题的规定》（2020 年修正，法释〔2020〕21 号）。

这件书面线索写：临颍县农业生产资料公司第十门市部，统一社会信用代码 `91411122MA3X5F2N1Q`，负责人王菊香。请查她是否在职、是否发工资、是否缴社保；已经退休就改查养老金发放账户。查的是她个人收入。分支机构和总公司的账户不是她的财产，不能因为总对总查不到她，就把这两家追加为被执行人。

立案后法院仍只跑总对总、不去核这份线索，再由代理律师申请律师调查令。

### 财产保全

保全和执行查控不是一回事。保全是在执行立案前把已经能定位的财产先控住。这件从 2025-07-29 受理到 2026-10-16 仍未确认执行立案，中间没有保全裁定，存款和车辆可以转走。等总对总，补不回这段空档。

先打 12368 问判决是否生效。两条路不要混：

- 还在上诉期，或者已经上诉：判决未生效。保全按诉中，向正在审理的法院提。民间借贷不在免担保清单里。法院可以要求担保。现金担保常见口径不超过拟保全金额的 30%，也可以用诉讼保全责任险。免担保不是权利，只是法院可以不要求。
- 已经生效、尚未立案执行：可以申请执行前保全。依据《最高人民法院关于人民法院办理财产保全案件若干问题的规定》（2020 年修正）第九条，这个阶段法院可以不要求提供担保。申请书写明源汇区法院、案号（2025）豫1102民初4348 和判决主文，并附判决副本。裁定一般移送执行机构实施。

申请书必须写明确的财产，或者具体线索。没有账号、没有房产证号、没有车牌，法院不会凭姓名去全库盲冻。保全阶段要用网络查控，得先有裁定，再书面申请在保全数额内查询。查不到，法院书面告知。这和执行立案后的总对总不是同一个开关。

能保全的是王菊香名下的存款、车辆、房产。第十门市部和总公司的账户不是她的财产，不能拿去保全。工资、养老金仍然要具体线索，生活必需费用不能冻。保全错了对象，申请人要赔对方因此受到的损失。

存款冻结最长不超过一年，动产查封最长两年，不动产和其他财产权最长三年。续行要在期限届满 7 日前提出。过期不提，自己承担续不上的后果。执行立案后，保全自动转为执行中的冻结，期限接着算，不重新起算。

保全另有申请费。数额问 12368，这里不估。责令担保时，存款类担保数额常见不超过请求保全数额的百分之三十，以当次窗口口径为准。

### 申请强制执行

胜诉不会自动进入执行。民间借贷要债权人自己申请。这件到 2026-10-16 还没申请，也还没有执行案号。

先打 12368 确认三件事：判决是否生效、对方是否上诉、是否已经有人立案执行。未生效不能当执行案件立。已经生效，向源汇区法院申请，不要同时向临颍县法院申请。

期间是 2 年。民事诉讼法（2023 年修正）第 250 条：文书写了履行期的，从履行期最后一日起算；分期履行的，从最后一期届满日起算；没写履行期的，从生效日起算。现有主文摘录没有「十日」原句。不要把常见的十日履行期写成这份判决已经写明。生效日被院印挡住，起算日以 12368 查到的生效日为准。超过 2 年仍可能收下材料；对方提出时效异议且成立的，可以不予执行。

材料：

- 强制执行申请书。写案号（2025）豫1102民初4348、被执行人王菊香、本金 358000 元及判决确定的利息和案件受理费 6670 元、已知财产线索。
- 判决复印件。原件自己留，除非窗口要原件。
- 申请人身份证明。委托律师或近亲属的，另附授权委托书和关系证明。
- 送达地址确认书、收款账户。
- 财产线索可以后补。没有线索也可以先立案。立案后总对总才启动。

河南自 2021-07-19 起，向本省中级法院、基层法院申请执行，不用当事人另交生效证明。

申请书里只请求：立案执行；网络查控；按书面线索查王菊香是否从第十门市部领工资或缴社保，已退休则查养老金；对查到的个人收入，扣留超过生活费的部分。不请求把第十门市部或总公司列为被执行人。终本、债权转让都排在立案并查财产之后。

提交顺序：人民法院在线服务能传就先网上提交，网址 https://zxfw.court.gov.cn/ 。网上被退回，再按 12368 给的窗口地址用 EMS 寄，或本人到场。签收和页面显示「已提交」都不是立案。要拿到执行案号，再打 12368 核对。

执行申请费依法由被执行人负担。窗口是否要求先垫，问 12368，这里不估。

立案后不要只等。书面财产调查表和第十门市部线索同一天交。法院仍只跑总对总，再申请律师调查令。
